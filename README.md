# Lucas Pelizer — Nutricionista

Landing page profissional para apresentação de serviços e agendamento de consultas de nutrição esportiva.

![Página inicial do Lucas Pelizer Nutricionista](docs/screenshot.png)

## Sobre o projeto

Desenvolvi esta landing page para o nutricionista esportivo e atleta Lucas Pelizer. O objetivo foi estruturar um canal direto para apresentar sua metodologia de acompanhamento individualizado, credenciais acadêmicas, modalidades de planos e facilitar o primeiro contato de novos pacientes via WhatsApp.

## Funcionalidades

- Seção de apresentação profissional com formação acadêmica, especializações e atuação no esporte
- Detalhamento da metodologia e etapas do acompanhamento nutricional
- Tabela comparativa de planos (Consulta Individual e Acompanhamento Trimestral) com itens inclusos
- Seção de perguntas frequentes (FAQ) interativa para esclarecimento de dúvidas comuns
- Botões de chamada para ação com links diretos para o WhatsApp e mensagens personalizadas
- Menu de navegação responsivo adaptado para dispositivos móveis

## Tecnologias

- HTML5 semântico
- CSS3 puro (Grid, Flexbox e variáveis CSS)
- JavaScript puro (Vanilla JS para controle de menu e interações)
- Phosphor Icons

## Como rodar localmente

Por ser um projeto estático, não há dependências de compilação ou execução:

1. Clone o repositório:
```bash
git clone https://github.com/marcoserculianipw/lucaspelizer-nutricionista.git
```
2. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server no VS Code.
